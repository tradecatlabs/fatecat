# 本地工具与验证入口

## 治理包校验

```bash
python3 skills/auto-governance/scripts/validate_governance_package.py --project-root . --strict
python3 skills/auto-governance/scripts/governance_health_report.py --project-root . --strict
```

## 任务树校验

```bash
python3 skills/auto-tasks/scripts/validate_tasks_tree.py --tasks-dir governance/tasks --phase auto --format markdown
```

## SOP 库校验

```bash
.venv/bin/python -m pytest -q tests/regression/test_sop_library.py
```

该门禁检查每份 SOP 的固定章节、索引覆盖、自然语言 route key/alias 唯一性、脚本路径和 capability registry 状态。SOP 真相源位于 `governance/processes/sops/INDEX.md`。

## 项目自身验证

使用项目已有的 package manager、test、lint、typecheck、benchmark 或 CI 命令；治理包不发明项目不存在的验证入口。

## 算准网研究语料

```bash
uv pip install --python .venv/bin/python -e '.[data]'
.venv/bin/python -m pytest -q tests/regression/test_suanzhun_corpus_crawl.py
.venv/bin/python scripts/suanzhun-corpus-crawl.py \
  --output infra/runtime/local-state/exports/suanzhun-corpus \
  --allow-external-media \
  --external-media-host mmbiz.qpic.cn
.venv/bin/python scripts/suanzhun-corpus-crawl.py \
  --output infra/runtime/local-state/exports/suanzhun-corpus \
  --validate-only
```

该入口只生成忽略的本地研究语料；`crawl.sqlite3` 是增量状态真相源，`records/documents.ndjson` 是逻辑文章记录，`manifests/document-pages.ndjson` 是逐物理详情页追溯证据，`reports/completeness.json` 与 `files.sha256` 是复核入口。完整性校验必须同时检查 `1..N` 页序列和不依赖分类器的原始详情 href 扫描。外部媒体主机只在运行环境的代理 DNS 使公开地址校验失真、且该主机已人工核验时显式加入白名单；不得用通配或关闭安全校验代替。语料在版权人工审查前不得进入 canonical 数据产品或公开分发。
