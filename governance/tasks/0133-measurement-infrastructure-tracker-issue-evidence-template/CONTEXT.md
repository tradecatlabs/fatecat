# Assumptions and Falsification

- Assumption: GitHub issue refs can be represented as `github:<owner>/<repo>#<number>`. Falsifier: another tracker is used; add a new sanitized ref namespace through contract, not raw URL.
- Assumption: package body sha256 is the immutable evidence binding. Falsifier: tracker mutates body content; add a tracker-rendered hash policy in a future task.
- Assumption: evidence artifact sha256 is generated by operator outside this task. Falsifier: repo gains an approved evidence upload store, then template can point to store-managed proof refs.
