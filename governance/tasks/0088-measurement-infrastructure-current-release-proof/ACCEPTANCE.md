# Review Gate

- Current proof must not accept a run whose `headSha` differs from current HEAD.
- Current proof must not accept non-`sha256:<64 hex>` digest.
- Current proof must not print tokens or raw `gh auth` output.

# Runtime Verification Gate

- Current release proof required mode must pass only after:
  - `origin/main == HEAD`
  - acceptance run for HEAD succeeds
  - container workflow for HEAD succeeds with release artifacts
  - GHCR image tag exists
  - GitHub attestation verifies
  - rollback drill evidence commit matches HEAD
