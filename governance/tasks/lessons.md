## 2026-07-12

- `/web` 三块工作台授权已撤销，当前不存在 CSS、视觉 class、颜色、圆角、卡片、响应式布局或装饰性容器例外。任何 `/web` 变更必须用 `tests/regression/test_web_html.py::assert_zero_beauty_semantic_html` 和 `bash scripts/local-ci.sh --profile quick` 证明禁用项没有回潮。
- 开发环境中存在可选依赖不能证明生产环境具备同一行为。凡可选 extra 会改变用户可见输出，必须进入运行依赖和运行锁，并用精简生产镜像对比本地输出；本次 `tabulate` 缺少 `widechars/wcwidth` 导致 HF 与本地中文 psql 表格不一致。
- 用户明确地区交互形态时，后端 capability 不能等价映射为前端控件；Web 只暴露用户最终确认的最小交互，本轮最终是单输入框模糊搜索与完整路径候选，地区模式、时区口径和 DST 等能力保留在 API/后端。
- 搜索输入不得擅自增加用户未要求的最小字数门槛；地点 API 已支持单字符查询时，Web 必须从第一个非空字符开始检索，并用回归测试锁定前后端契约一致性。
- 原生候选列表已经表达搜索结果时，不得在输入框旁重复增加“查找中、候选数量、未找到、已选择”等动态状态；必要错误只在提交边界通过浏览器原生校验或服务端错误呈现。

## 2026-07-15

- 称骨的“可计算重量集合”和“男女歌诀表覆盖范围”是两个不同边界：当前年月日时权重最高只能算到七两一钱，但男命歌诀表仍包含七两二钱，女命歌诀表止于七两一钱；不得为了对齐数据结构删除男命条目，也不得只抽查上界后宣称男女版本完整。
- 面向用户的称骨 Markdown 必须统一使用中文量词格式，总重和四项构成都不得输出 `3.7两`、`1.3两` 等小数表达；机器字段可继续保留整数“钱”和兼容数值字段。
- FastAPI lifespan 中的 Telegram、Webhook 等外部初始化必须有运行时级总超时；捕获异常不能覆盖“外部 await 永不返回”，降级交付面不得阻塞核心 Web/API 启动。
