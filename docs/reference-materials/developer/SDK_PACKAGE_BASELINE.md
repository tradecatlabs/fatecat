# FateCat SDK Package Baseline

The current developer SDK baseline is intentionally limited to installable examples and package metadata.

## Current Assets

- Python example: `docs/reference-materials/developer/examples/python-client.py`
- Node example: `docs/reference-materials/developer/examples/node-client.mjs`
- curl example: `docs/reference-materials/developer/examples/curl-sandbox.sh`
- Agent tool-call example: `docs/reference-materials/developer/examples/agent-tool-call.json`

## Publication Boundary

- No PyPI package is currently claimed.
- No npm package is currently claimed.
- `bash scripts/developer-docs-smoke.sh` proves local examples and sandbox fixtures, not external package publication.
- Real SDK release requires package metadata, versioning, registry publish evidence and install smoke in a later task.
