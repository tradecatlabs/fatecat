# FateCat 测算基础设施路线图

> 状态：执行中
> 范围：把 FateCat 从命理工具集合升级为面向 Agent 与应用开发者的测算基础设施。

## 定位

FateCat 是面向 Agent 与应用开发者的测算基础设施，提供统一的能力协议、可复现计算核心、证据化解释层和多端交付接口。

## 目标终态

FateCat 的长期形态不是把八字、紫微、六爻、奇门等模块直接堆在一个报告里，而是提供一套基础设施：

- 统一能力协议：每个体系都是独立 capability，具备输入、输出、证据、风险、可见性和成熟度契约。
- 可复现计算核心：底层优先复用成熟库和已登记供应链，计算结果带 provider、engineVersion 和 determinism 标记。
- 证据化解释层：解释结论必须能追溯到 ruleId、source、basis、weight、confidence 或明确的不可断言边界。
- 多端交付接口：Web、API、Bot、Skill、Agent 调用同一个 capability executor，不允许各端自行拼核心结果。
- 质量门禁：能力升级必须经过 schema、golden、snapshot、privacy、vendor health 和 public release gate。

## 五阶段路线

| 阶段 | 目标 | 交付物 | 验证 |
| --- | --- | --- | --- |
| 定位基线 | 统一仓库主叙事 | README、SKILL、AGENTS、branding、路线图 | `bash scripts/local-ci.sh --profile quick` |
| 协议基线 | capability registry 可表达基础设施成熟度 | `registry.json` 增加 maturity、engineVersion、evidencePolicy、testGate | `tests/regression/test_capability_protocol.py` |
| 执行器基线 | 所有生产能力通过统一 executor 执行 | provider map、planned 拒绝执行、执行 metadata | capability focused tests |
| 八字/紫微标杆 | 让 bazi/ziwei 成为新体系接入模板 | 标杆 profile、evidence gate、golden/snapshot 声明 | bazi/ziwei regression |
| 生产基础设施 | 对外提供稳定服务面 | `/capabilities`、`/capabilities/{id}/calculate`、`/reports`、`/metadata`、health/ready/metrics/rate limit | API contract tests + public release gate |

## 能力成熟度

| 等级 | 状态 | 含义 |
| --- | --- | --- |
| L0 | registered | 已登记，不能执行 |
| L1 | prototype | 可本地 demo，不进入生产 API |
| L2 | integrated | 接入统一 executor，有基础协议测试 |
| L3 | validated | 有 golden、snapshot、evidence 与隐私回归 |
| L4 | production | Web/API/Bot/Skill 同源输出，可审计交付 |

## 首批生产样板

| capability | 目标等级 | 当前策略 |
| --- | --- | --- |
| `bazi` | L4 | 默认综合八字报告；继续加固节气、真太阳时、格局用神、报告结构和 evidence。 |
| `ziwei` | L4 | 独立紫微 capability；继续补星曜、宫位、四化、运限和 golden。 |
| `almanac` | L3 | 独立黄历择日 capability；作为非默认生产能力继续补规则深度。 |
| `meihua` | L3 | 独立占事 capability；只输出盘面、体用和证据，不输出确定性断语。 |
| planned 能力 | L0 | 六爻、奇门、大六壬、风水九星、姓名合婚等只登记，不进入默认报告。 |

## 不做事项

- 不把未来体系塞回默认综合八字报告。
- 不把 planned / experimental 能力伪装成 production。
- 不让 LLM 自行重算命盘、起盘或补造规则。
- 不为了功能数量降低 evidence、privacy、source hygiene 和 release gate。
- 不在 vendor 快照里魔改第三方源码。
